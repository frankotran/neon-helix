# NEON HELIX

Helix-drop arcade + color-match twist. Drag to spin the tower, fall through
gaps, land only on your color, grab repaint rings, dodge red spikes.

- `index.html` — shell + all UI overlays
- `style.css` — neon UI
- `game.js` — engine (physics, levels, shop, procedural audio, ad architecture)
- `MONETIZATION.md` — ad placement plan + native App Store path

Zero assets, zero cost: canvas rendering + WebAudio. Mobile-first portrait.

## Test hooks
`window.NH` exposes state/start/setRot/score/skipAd for headless QA.
